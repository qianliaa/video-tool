# 常见问题

## 任务一提交就失败，日志显示找不到 ffmpeg

后端按 `PATH`、`/usr/bin`、`/usr/local/bin`、飞牛应用目录依次查找 `ffmpeg` / `ffprobe`，两者都要有。

- fnOS 部署：确认系统里已安装 ffmpeg（含 ffprobe），或用应用中心里带 ffmpeg 的运行时。
- Docker 部署：镜像已内置 ffmpeg，若仍报错说明容器被替换过镜像。

## 输入 / 输出目录里看不到我要的文件夹

目录必须先在「系统设置 › 应用 › 视频助手 › 访问权限」里授权，应用内只能从已授权目录中浏览选择，不支持手填路径。授权变更后无需重启，重新打开目录选择器即可。

另外：应用自身目录不能作为输入 / 输出目录；输入与输出**可以是同一目录**。

## 输出文件名重复会覆盖吗

不会。同名输出会自动追加 `(1)`、`(2)`。输出支持子目录写法，例如 `out/result.mp4`。

## 直链 / 网页地址下载失败

需要登录、DRM 保护或站点私有协议的地址不支持。可尝试在下载选项中补 `User-Agent`、`Referer`、请求头或代理；HLS（m3u8）可直接选画质，DASH（mpd）与网页公开媒体地址（`og:video`、`<video>`、`contentUrl`、iframe）会自动解析。

## 端口 18080 被占用

先确认占用进程：飞牛上执行 `ss -ltnp | grep 18080`。改用其他端口可设置环境变量 `VT_BIND_PORT`（监听地址用 `VT_BIND_HOST`）。Docker 部署时改 `docker-compose.yml` 的端口映射即可。

## 任务一直排队

下载与转码是两个独立队列，默认并发 3 / 2，可通过 `VT_MAX_DOWNLOADS`、`VT_MAX_TASKS` 调整（各自上限 8）。调高前先确认 NAS 的 CPU 与内存余量。

## 「关于与更新」提示接口限额

未登录的 GitHub API 每小时限 60 次，可设置环境变量 `VT_GITHUB_TOKEN` 提升限额；也可用 `VT_GITHUB_API` 指向自建代理。

## 合并后音画不同步 / 失败

无损拼接要求所有输入的编码参数一致；参数不一致时勾选「强制统一重新编码」。字幕烧录同样会重新编码，不支持无损。

## 局域网外能访问吗

服务默认监听 `0.0.0.0:18080`，**免登录、无 TLS / CSRF 校验**。不要直接暴露到公网，请通过网关或防火墙限制访问，必要时叠加反代与访问控制。
