视频助手 独立桌面版（Windows / Linux）
=====================================

这是一个免安装绿色版：解压后直接运行，无需 fnOS，也无需系统预装 ffmpeg
（ffmpeg / ffprobe 已随包内置在 bin/ 目录）。所有视频处理均在本机完成，
全程不连接任何外网。

【首次使用】
1. 解压整个 video-tool 文件夹到任意位置（路径建议不含中文/空格）。
2. 双击 video-tool.exe（Windows）或运行 ./video-tool（Linux）。
   —— 会直接弹出原生操作面板（Tkinter 窗口），无需浏览器、无需联网。
3. 在「工具」里选一个功能（下载 / 转换 / 压缩 / 剪辑 / 提取音频 / 合并 /
   字幕 / 缩放 / 旋转 / 截图 / 自定义）。
4. 在每个工具内直接选择「输入文件」与「输出路径」（点“选择…”按钮浏览本机
   任意位置，选好输入后会自动给出同目录的输出默认名，可随手改）。
   下载工具选「保存目录」即可，无需预先配置工作目录。
5. 点“开始处理”，在「任务」里查看进度、日志，必要时可取消任务。

【任务列表批量操作】
- 点击列表首列的方框（☐ → ☑）勾选任务，也可用「全选」「反选」。
- 工具栏按钮：「开始 / 继续」（暂停中的任务接着处理，已结束的任务重新执行）、
  「暂停」（挂起运行中或排队中的 ffmpeg 任务）、「取消」、「删除」，
  以及「清除已结束」一键清理已完成 / 失败 / 已取消的任务记录。
- 暂停后进度会停住，点「开始 / 继续」从原位置接着处理，不会从头重跑。
- 删除只移除任务记录，不会删除已经生成的视频文件；删除运行中的任务会先取消。

【操作面板说明】
- 这是一个纯原生桌面窗口，所有操作都在本机完成，不打开浏览器、不访问网络。
- 后台由本机 127.0.0.1:18080 的 HTTP 服务完成真正的处理（ffmpeg 调用）。
- 输入/输出支持本机任意绝对路径，选中输入文件后会自动建议同目录输出路径。
- “退出”：停止服务并退出（直接关闭窗口等效）。

【目录结构】
  video-tool/
  ├─ video-tool.exe        # Windows 主程序（含原生操作面板）
  ├─ video-tool            # Linux 主程序
  ├─ start.bat / start.sh  # 启动脚本（等效于双击主程序）
  ├─ README.txt
  └─ bin/
     ├─ ffmpeg.exe / ffmpeg
     └─ ffprobe.exe / ffprobe

【数据存储】
- 配置与任务记录位于用户目录：
    Windows: C:\Users\<你>\.video-tool
    Linux:   ~/.video-tool
  删除该目录即可重置所有设置。

【高级环境变量（一般无需修改）】
  VT_BIND_HOST   监听地址，默认 127.0.0.1（仅本机）
  VT_BIND_PORT   监听端口，默认 18080
  VT_STANDALONE  固定为 1（独立桌面模式，绕过 fnOS 授权）

【常见问题】
- 面板提示“正在启动本地服务…”？首次约需几秒，请稍候；若长时间不行，
  检查 bin/ 下 ffmpeg 是否存在，或设置 VT_BIND_PORT 改为其它端口后重启。
- 端口被占用？设置环境变量 VT_BIND_PORT 为其它端口（如 18081）后重启。
- 处理任务失败提示缺 ffmpeg？确认 bin/ 目录下存在 ffmpeg 与 ffprobe。
