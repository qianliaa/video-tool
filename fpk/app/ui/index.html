    目录设置

    可直接粘贴「文件管理」中复制的原始路径，例如 /vol1/1000/视频。保存时会自动检查读写权限。

    在应用里看不到文件夹？

    先到 fnOS「系统设置 › 应用 › 视频助手 › 访问权限」添加并授权文件夹，再把该文件夹的原始路径粘贴到上方。应用不再使用自身目录作为输入输出。

    环境信息

    使用提示

    • 所有处理都在本机完成，视频不会上传到任何服务器。
    • 输入目录会递归读取子文件夹，文件列表显示相对路径。
    • 输出文件名支持子目录，例如 out/result.mp4。
    • 下载使用 ffmpeg 原生能力，支持直链、HLS、DASH 与页面公开地址。

    注册与主账号

    -

    主账号说明：飞牛主账号能通过官方统一网关下发的 X-Trim-Username / X-Trim-Userid / X-Trim-Isadmin 请求头识别；本应用使用端口服务入口，官方文档明确端口服务不携带 NAS 登录态，因此实际拿不到飞牛账号，按「首个完成注册的账号为主账号」处理，不伪装成已识别。README 中同样写明了该限制。

    用户管理

    新增用户

    账号名支持 2-32 位字母、数字、下划线、点或短横线；密码至少 8 位且需同时包含字母和数字。普通用户可使用下载与处理功能，但看不到用户管理；主账号不可删除或停用。

    关于与更新

    尚未检查

    点击「检查更新」查询 GitHub Releases。未登录 GitHub API 每小时限 60 次；检查失败只在本卡片提示，不影响任务与其他功能。
